# Секционирование и шардирование

## RANGE, LIST, HASH

Скрипт [partitioning.sql](partitioning.sql) создает три секционированные таблицы,
наполняет их тестовыми данными и выполняет по одному `EXPLAIN (ANALYZE, BUFFERS)`.

Ожидаемый результат:

| Тип | Условие | Результат pruning |
| --- | --- | --- |
| `RANGE` | диапазон `opened_at` за февраль | участвует февральская секция |
| `LIST` | `region = 'kazan'` | участвует секция `service_visit_volga` |
| `HASH` | `client_id = 42` | участвует одна из четырех hash-секций |

Индексы объявлены на родительских таблицах и создаются для секций автоматически.

## Репликация секций

При физической репликации WAL переносит изменения файлов и каталога PostgreSQL,
поэтому standby получает секционирование без отдельной настройки и не должен
интерпретировать структуру секций.

Для логической репликации подготовлен
[logical_partitioning.sql](logical_partitioning.sql): он показывает разницу
между `publish_via_partition_root = false` и `true`.

## Шардирование через postgres_fdw

[fdw_router.sql](fdw_router.sql) настраивает router для двух удаленных серверов,
импортирует таблицу `repair_order`, создает общее представление и строит планы
для запроса по всем данным и запроса к одному шарду.

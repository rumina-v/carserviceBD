# OLAP-модель автосервиса

В отдельной схеме `olap` построена звезда:

```text
dim_date ----+
dim_client --+--> fact_service_order
dim_service -+
```

Главный факт: оказанная услуга в заказе. Зерно факта: одна строка соответствует
одной услуге одного заказа.

Аналитические вопросы:

1. Как меняются выручка и количество оказанных услуг по дням?
2. Какие услуги наиболее популярны и какую выручку они дают?
3. Какие клиенты принесли наибольшую выручку?

[schema.sql](schema.sql) создает измерения и факт, а также заполняет календарь.
Внизу файла оставлен шаблон идемпотентной загрузки измерений из OLTP.
[analytics.sql](analytics.sql) содержит три аналитических запроса.

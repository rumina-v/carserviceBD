# Airflow: бонусная часть

В презентации Airflow отмечен как дополнительное задание, поэтому этот каталог
не относится к обязательным ДЗ. Ниже зафиксирован план расширения проекта:

```text
CSV со справочником услуг ----+
                              +--> Airflow DAG 1 --> PostgreSQL carservice
JSON с плановыми показателями +

PostgreSQL carservice --> Airflow DAG 2 --> ClickHouse --> витрина выручки
```

Требования к реализации:

1. DAG 1 загружает два разных источника и использует upsert для идемпотентности.
2. DAG 2 переносит факты из `olap.fact_service_order` в ClickHouse.
3. Перед загрузкой проверяются отсутствие пустых ключей и неотрицательные суммы.
4. В ClickHouse строится дневная витрина: дата, количество услуг, выручка.

Каталог оставлен отдельно, чтобы бонусная часть не выглядела как выполненная без
запущенного Airflow и скриншотов DAG.
